## ✅ Replit AI Prompt (paste everything below)

**Project:** RAAP — Reminder as a Service (Flask, Python)
**Context:** The app already has routes `/`, `/add`, `/done/<id>`, `/wallpaper.png` and a helper `load_tasks()` that returns Task objects with fields like `.text` and `.done`.

**Goal:** Add Siri integration by implementing two read-only endpoints without breaking existing behavior:

1. `GET /api/tasks` → returns JSON of pending and done tasks
2. `GET /api/say` → returns `text/plain` sentence summarizing pending tasks (for Siri to speak)

**Security:**
Support an optional shared key via env var `API_KEY`.

* If `API_KEY` is set, require the query param `?key=<API_KEY>` on both endpoints.
* If `API_KEY` is **not** set, allow public read access.

**Requirements & Constraints:**

* Keep all existing routes and logic intact.
* Reuse the existing `load_tasks()` function to read tasks.
* No writes or side effects in the new endpoints.
* Use `flask.jsonify` for JSON; for `/api/say` return `text/plain; charset=utf-8`.
* Status codes: `200` on success, `401` on missing/incorrect key when `API_KEY` is set.
* No new dependencies required.

**Data shape for `/api/tasks`:**

```json
{
  "pending": ["Pay rent", "Call mom"],
  "done": ["Buy milk"]
}
```

**Text rules for `/api/say`:**

* No pending tasks → `You have no pending tasks.`
* 1 task → `You have one task: <task>.`
* 2–5 tasks → `You have N tasks: task1; task2; ...; taskN.`
* More than 5 tasks → read first 5, then append `And M more.` (where M = remaining count).

### 🔧 Implementation: insert the following **near the other @app.route handlers** in `main.py`

```python
# --- Siri / Assistant API endpoints ---
import os
from flask import request, jsonify, Response

API_KEY = os.getenv("API_KEY")

def _check_key():
    """Return True if access is allowed. If API_KEY is set, require ?key=..."""
    if not API_KEY:
        return True
    return request.args.get("key") == API_KEY

@app.route("/api/tasks")
def api_tasks():
    if not _check_key():
        return jsonify({"error": "unauthorized"}), 401
    tasks = load_tasks()
    pending = [t.text for t in tasks if not t.done]
    done = [t.text for t in tasks if t.done]
    return jsonify({"pending": pending, "done": done})

@app.route("/api/say")
def api_say():
    if not _check_key():
        return Response("Unauthorized", status=401, mimetype="text/plain; charset=utf-8")

    tasks = load_tasks()
    pending = [t.text for t in tasks if not t.done]

    if not pending:
        text = "You have no pending tasks."
    elif len(pending) == 1:
        text = f"You have one task: {pending[0]}."
    else:
        first = pending[:5]
        remainder = len(pending) - len(first)
        listing = "; ".join(first)
        text = f"You have {len(pending)} tasks: {listing}."
        if remainder > 0:
            text += f" And {remainder} more."

    return Response(text, mimetype="text/plain; charset=utf-8")
```
